# EV Omnichannel Sales & CX Funnel Analytics (CRM + DMS Reconciliation)

An end-to-end BI project for a two-wheeler EV OEM: reconcile **CRM leads**, **dealer-management (DMS) bookings** and **customer-experience tickets** into one funnel, find where sales leak, and track service-level (SLA) performance by store.

> **Note:** All data is synthetic, generated by `src/generate_data.py`. This is a portfolio project and is not affiliated with any real company.

## The business problem
Sales ops runs on three disconnected systems. Bookings can't always be traced back to the lead that created them, nobody can say where the funnel leaks, and CX escalations are chased manually. This project builds a reconciled funnel, store scorecards, and automated escalation.

## Key findings (from the generated data)
| Finding | Evidence |
|---|---|
| ~10% of DMS bookings can't be joined to CRM | 29 of 286 bookings; 11 recoverable via key cleaning + CX healing, 18 remain unattributed |
| **Test Ride → Booking is the bottleneck** | Marathahalli ≈ 45% vs 65–89% at other stores |
| Same store has the worst CX | SLA breach rate ≈ 70% vs 0–50% elsewhere; slower VIN assignment and more cancellations |
| 37 tickets meet the critical rule | `TAT > 24h AND CSAT ≤ 2` → auto-flagged `CRITICAL_ESCALATION` |

## Tech stack
Python (pandas, numpy, faker) · SQL (PostgreSQL syntax) · Google Sheets (QUERY, FILTER, XLOOKUP, ARRAYFORMULA, IMPORTRANGE) · Google Apps Script · Power BI (DAX, Power Query)

## Repository structure
```
├── data/          3 CSV datasets (500 leads, 286 bookings, 200 tickets)
├── src/           generate_data.py: reproducible data generator
├── sql/           reconciliation.sql: joins, orphan/unlinked detection, KPI queries
├── apps_script/   escalation.gs: automated ticket escalation
├── powerbi/       dashboard (.pbix)
├── images/        screenshots
└── docs/          PROJECT_GUIDE.md: metric definitions, Sheets formulas, DAX, dashboard blueprint
```

## How to run
```bash
git clone https://github.com/<shreyashanalytics>/ev-omnichannel-analytics.git
cd ev-omnichannel-analytics
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python src/generate_data.py data                       # regenerates the 3 CSVs + prints QA stats
```
